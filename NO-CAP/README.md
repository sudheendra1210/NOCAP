# NO CAP

NO CAP landing page.

## Structure
- `index.html` — page markup
- `style.css` — styles
- `script.js` — countdown + rotating Three.js hero model
- `community.js` — public theories, local prototype storage, and profile placeholder panels
- `auth.js` / `auth-ui.js` — shared Clerk instance and custom authentication UI
- `assets/logo.png` — NO CAP logo used in the header and model fallback
- `assets/dancer.glb` — 3D hero model
